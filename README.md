\# practica-git-cuy6142



Repositorio de práctica de Git y GitHub - CUY6142



\## Contenido



\- \*\*pokeapi.py\*\*: consulta datos de cualquier Pokémon ingresado por el usuario en la API pública PokeAPI. Devuelve nombre, número, altura, peso, tipos y habilidades.

\- \*\*clima.py\*\*: consulta de clima usando variable de entorno.



\## Ejecución



\- Consulta directa por argumento: `python pokeapi.py charizard`

\- Modo interactivo (pide el nombre por pantalla hasta escribir “salir”): `python pokeapi.py`



\## Requisitos



\- Python 3

\- Librería requests: `pip install requests`



\## Ramas



\- `main`: rama principal con el código en producción.

\- `consulta-pokemon`: rama secundaria donde se desarrolló la consulta dinámica, fusionada a main.
